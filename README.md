# Crew & Impostor (no Node.js needed)

Files (all in the repo root): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

1. GitHub: New repository > Add file > Upload files > drag all files > Commit.
2. Settings > Pages > Deploy from a branch > main / (root) > Save.
3. Your game is at https://YOUR-NAME.github.io/REPO-NAME/
4. App: open the link on your phone (Chrome) > menu > Install app. On PC use Chrome/Edge > Install icon in the address bar.
5. Real .apk / Windows package without Node: https://www.pwabuilder.com, paste your link.

Multiplayer: host picks PeerJS or Relay (use Relay if PeerJS is blocked). Relay room codes have 5 characters; players just type the code and press Join.
